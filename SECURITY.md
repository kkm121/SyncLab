# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within SyncLab, please report it privately to the repository owner. Please include:
- A description of the issue.
- Steps to reproduce or proof-of-concept payload.
- Affected endpoints or models.

All reports will be acknowledged within 7 business days.
